# Dirección creativa — Scooby, siempre contigo

## Concepto

La experiencia se construye alrededor de una idea sencilla: **sus huellas permanecen**. No es un funeral digital ni una colección de módulos; es un recorrido de oscuridad a luz que recuerda la ausencia y, sobre todo, celebra que Scooby existió.

## Narrativa

1. **Preludio:** oscuridad, silencio y huellas que aparecen con calma.
2. **Revelación:** Scooby ocupa la pantalla y establece el tono íntimo.
3. **Tiempo:** las fechas, el contador y la historia reconocen la pérdida sin convertirla en estadística.
4. **Recuerdos:** las fotografías reales toman el protagonismo editorial.
5. **Regalo:** se revela que este lugar también fue creado para quien recibe el enlace.
6. **Carta:** un momento táctil y personal, como una hoja conservada.
7. **Celebración:** la noche cambia gradualmente a amanecer y ocho luces representan ocho a\u00f1os.
8. **Camino:** el paisaje final convierte la huella en permanencia.
9. **Epílogo:** el último recuerdo es alegre, con Scooby y su juguete.

## Paleta

- Midnight `#07111D`: base y silencio.
- Deep Navy `#0B1726`: profundidad.
- Warm Ivory `#F7F0E5`: texto principal.
- Soft Gold `#D7A75C`: línea temporal y pequeños acentos.
- Amber Light `#F3C879`: luz emocional.
- Muted Gray `#9BA6B2`: texto secundario.

El dorado se utiliza como luz, no como superficie decorativa.

## Tipografía

Los títulos utilizan una pila serif editorial (Georgia/Times). La interfaz usa Segoe UI y fuentes del sistema para evitar cargas externas. Los detalles manuscritos se resuelven con cursiva serif muy controlada, nunca en bloques largos.

## Fotografía

Solo se usan fotografías reales provistas. Los tratamientos se limitan a encuadre, contraste, saturación sutil, gradientes y sombras. La identidad de Scooby no se altera. El hero elige la fotografía horizontal sonriente; el epílogo reserva la imagen del juguete para cerrar con alegría.

## Movimiento

Las entradas duran entre 1 y 1.5 segundos con curvas suaves. No hay rebotes ni movimientos agresivos. La fotografía hero respira mediante un zoom mínimo. `prefers-reduced-motion` elimina las transiciones y revela todo el contenido inmediatamente.

## UX y accesibilidad

- Mobile first y escenas recompuestas para pantallas estrechas.
- Botones reales, foco visible, textos alternativos y navegación por teclado en el lightbox.
- El video nunca se reproduce solo.
- La música solo puede comenzar después del gesto de entrada y se mantiene desactivada mientras no haya un archivo local configurado.
- La experiencia conserva un fallback visible aun si JavaScript o algún recurso falla.

## Principios para cambios futuros

- Si un elemento no aporta memoria o ritmo, se elimina.
- Una fotografía real tiene prioridad sobre texto adicional.
- Una transición sutil tiene prioridad sobre una animación llamativa.
- No introducir nombres, relaciones, historias o datos que no hayan sido confirmados.
